## Kimera core

### IMU pre-integration

- ~ From a keyframe $i$, the changes of the pose $R_i$ to a new frame $j$ are a product of poses
- ~ We can use $R_t^\top R_j$
- ~ No need to recompute everything, when changing 
- Structureless projection factor
  - Similar to marginalization, in a way
  - Eliminating the unrequired variables
    - Not interested to know where the landmarks are, what we want to know is the robot location

- Pose optimisation
  - Eliminating landmark locations
  - $\mathcal{X}(l)$ is the set of image frames from which the $l$-th landmark is visible
  - Reprojection error, a bunch of residual errors

    $$
    \sum_{l = 1}^{L} \sum_{i \in \mathcal{X}(l)} {\Vert \Vert}^2
    $$

- Fixed LAG smoothing
  - Past data

### Two views: (Stereo) Epipolar geometry

- SfM (Structure from Motion) problem
  - Need to estimate the camera correspondance, and the location of the 3D point
  - Essentially a giant non-linear least squares problem
- Epipole line, Epipole plane
- Choosing one camera as reference, i.e., it's extrinsic matrix essentially is taken as identity
- Estimating pose of the other camera
- $F \to$ Fundamental matrix
  - Rank 2 $\implies \det F = 0$
  - $3\times 3$ matrix with 8 free parameters, (upto scale)
- Everything in projective geometry is upto a scale
- The scale multiples entire matrix, so $x^\top F x = 0$, scaled versions also satisfy
- Using 8 point correspondences, one can calculate $F$
  - But also can just use 5 point correspondences with 2 additional constraints
  - Rank 2 and another cubic constraint
- Run on RANSAC later; 5 point RANSAC for geometric verification
